# java-lotto-precourse

### 자료구조 정의

---

- `Lotto` 클래스
    - [ ] 각 로또의 6개의 로또 번호 중 당첨 번호와 일치하는 번호가 몇개인지 구하는 메서드를 추가한다. 
        - 몇 개의 번호가 일치하는지 구하고, 그 일치하는 개수에 해당하는 로또의 수를 increment하는 `WinningLottoMatcher`의 setter를 호출한다.
- [ ] `WinningLottoMatcher` 클래스
    - [ ] 1등부터 5등까지 각각 해당하는 로또의 개수를 저장하는 변수들을 갖는다.
    - [ ] 총 당첨 금액을 저장하는 변수를 갖는다.
    - [ ] 등수별로 해당하는 로또의 개수를 increment하게 해주는 `setter` 메서드를 갖는다. 총 당첨 금액에 해당 당첨 금액을 추가한다.
    - [ ] 구매한 로또 중 등수별로 당첨된 로또의 개수를 리턴하는 `getter` 메서드를 갖는다.

### 입력

---

- [ ] 로또 구입 금액을 입력받는다.
    - 입력은 1,000원 단위여야한다.
    - 형식을 지키지 않을 경우 예외 처리

- [ ] 6개의 당첨 번호를 입력받는다.
    - 입력은 ","를 기준으로 구분한다.
    - 각 숫자는 1~45이다.
    - 당첨 번호는 중복되지 않는 숫자 6개여야 한다.

- [ ] 1개의 보너스 번호를 입력받는다.
    - 보너스 숫자는 1~45이다.

### 출력

---

- [ ] 발행한 로또 수량을 출력한다.
- [ ] 발행한 로또별로 각각의 로또 번호 6개를 출력한다.
    - 로또 번호는 중복되지 않는 숫자 6개
    - 로또 번호는 오름차순으로 정렬해 출력한다.
- [ ] 당첨 통계를 출력한다.
    - 당첨번호와 일치한 로또 번호 개수를 기준으로 등수별로 각각 일치한 번호의 개수, 당첨 금액, 당첨된 로또의 개수를 출력한다
        - 당첨은 1등(6개 번호 일치)부터 5등(3개 번호 일치)까지 가능하다.
        - 5등부터 출력한다.
- [ ] 총 수익률을 출력한다.
    - 수익률 = 총 당첨 금액의 합 / 구입 금액
    - 소수점 둘째 자리에서 반올림
- 입력에서 예외가 발생하는 경우 "[ERROR]"로 시작하는 에러 문구를 출력한다.


### 실행

---

- [ ] 구입 금액을 입력받으면 그 금액으로 구매할 수 있는 로또의 수를 계산한다.
    - 구입 금액이 1,000 단위인지 체크한다.
- [ ] 구매한 로또의 수만큼 다음을 반복한다.
    - [ ] `Lotto` 객체를 생성하고 중복되지 않은 6개의 랜덤한 로또 번호를 생성한다.
- [ ] 당첨 번호와 보너스 번호를 입력받으면 당첨 통계를 출력한다. 5등부터 등수별로 다음을 반복한다.
    - [ ] 일치하는 번호의 개수, 당첨 금액, 해당 등수인 로또의 수를 출력한다.
    -[ ] 총 당첨 금액에 해당 당첨 금액을 더한다.
- [ ] 총 수익률을 출력한다.

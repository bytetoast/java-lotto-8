# java-lotto-precourse

### 프로젝트 소개

---

이 프로젝트는 구매 금액, 당첨 번호, 보너스 번호를 입력해서 하나의 로또 구매 시나리오를 제공하면 당첨된 로또의 개수와 해당 구매로 얻은 수익에 대해 분석해주는 프로그램입니다.

### 기능 목록

---

- 구매자와 로또 판매자
    - [x] 로또 판매자는 로또 판매를 시작하며 구매금액상태를 준비중으로 변환하고 손님에게 입력을 요구한다.
    - [x] 손님이 구입 금액을 입력한다.
    - [x] 로또 판매자는 유효한 입력값인지 확인한다.
        - **예외 상황**
            - 정수가 아니다.
            - 1,000원 단위의 금액이 아니다.
    - [x] 유효한 입력값이라면 로또 판매자는 해당 금액으로 몇 개의 로또를 살 수 있는지 계산한다.
    - [x] 로또 판매자는 구매한 로또의 개수별로 6개의 로또 번호를 생성한다.
    - [x] 로또 판매자는 생성된 로또 번호를 검증한 뒤 유효한 값이라고 판단되면 구매금액상태를 성공 상태를 변환하고 출력한다.
        - **예외 상황**
            - 생성된 번호가 6개보다 작거나 크다.
            - 중복되는 숫자가 있다.
            - 생성된 번호가 1이상 45이하의 숫자가 아니다.

- 작동자와 로또 머신
    - [x] 작동자가 로또 머신을 가동하며 당첨 번호 상태를 준비중으로 바꾸고 당첨 번호 입력을 요구한다.
    - [x] 당첨 번호 상태가 준비중인 동안 다음을 반복한다.
        - [x] 로또 머신은 당첨 번호 상태가 준비중인지 확인한다.
        - [x] 작동자가 당첨 번호를 입력한다.
        - [x] 로또 머신은 유효한 당첨 번호인지 확인한다.
            - **예외 상황**
                - 6개의 번호를 입력하지 않았다.
                - 번호가 쉼표로 구분되어 있지 않았다.
                - 숫자 중 중복이 있다.
                - 입력값이 1이상 45이하의 숫자가 아니다.
        - [x] 유효한 당첨 번호라면 당첨 번호 상태를 성공으로 바꾼다.
        - [x] 유효하지 않은 번호를 입력받았다면 에러 메시지를 출력하고 다시 당첨 번호 입력을 요구한다.
    - [x] 보너스 번호 상태를 준비중으로 변경하고 보너스 번호 입력을 요구한다.
    - [x] 보너스 번호 상태가 중비중인 동안 다음을 반복한다.
        - [x] 로또 머신은 보너스 번호 상태가 준비중인지 확인한다.
        - [x] 작동자가 보너스 번호를 입력한다.
        - [x] 로또 머신은 유효한 당첨 번호인지 확인한다.
            - **예외 상황**
                - 당첨 번호와 중복되는 숫자이다.
                - 입력값이 1이상 45이하의 숫자가 아니다.
        - [x] 유효한 보너스 번호라면 보너스 번호 상태를 성공으로 바꾼다.
        - [x] 유효하지 않은 번호를 입력받았다면 에러 메시지를 출력하고 다시 보너스 번호 입력을 요구한다.

- 구매자는 당첨 통계를 구한다.
    - [x] 등수별로 다음을 반복한다.
        - [x] 일치한 번호의 개수, 당첨 금액, 당첨된 로또의 개수를 출력한다.
        - [x] 당첨된 금액을 총수익에 더한다.
    - [x] 투자한 금액 대비 수익인 총 수익률을 구한다.
